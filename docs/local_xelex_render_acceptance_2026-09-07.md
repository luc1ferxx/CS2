## Operate this checkout

The App stack uses `.local/qa/compose-loopback.yml`, which enables `RENDER_WORKER_MODE=external` for API and parser worker and keeps their published ports on loopback.

```powershell
# App and CSDM database
docker compose -f docker-compose.yml -f .local/qa/compose-loopback.yml up -d
docker compose --env-file .local/renderer/.env -p cs2-renderer -f .local/renderer/compose.yml up -d

# Start the configured background render process
& .local/renderer/start.ps1

# Finish the current clip, then stop taking work
& .local/renderer/stop.ps1
```

Open the Nuke demo, select xelex and use `Generate Tick Clip` or a coaching card's clip action. The local worker handles one clip at a time. CS2 must be closed before it takes a job. A running game is left alone; queued work waits. The worker is not an installed Windows service and does not start automatically after reboot.
